## 一、结论先行（三句话）

1. **数据是通的**：数字北中医的门户 API 是一个标准 JWT 网关（`Authorization: Bearer`），已实测能用 curl 直连拿到 163 个应用、979 项服务、待办、日程、邮箱等全量数据，不依赖浏览器。
2. **移动端是空的**：学校没有官方 App、没有独立 m 站；移动能力全在「微信企业号 / 企业微信」里。163 个应用里真正有独立移动站的只有 **2 个**，真正响应式的只有 **1 个**。
3. **合规是硬门槛**：技术上能做的事，法律与备案上大部分做不了。个人身份**无法完成教育移动应用提供者备案**，公开上架这条路基本关死；学生团队唯一低成本出口是「校内自研自用」备案。

## 四、技术可行性结论

| 环节 | 结论 | 证据 |
|---|---|---|
| 取数据 | **可行**，REST + JWT，接口规范 | 已用 curl 直连拿到 429KB 应用清单 |
| 拿 JWT | **这是全部难点**。CAS 无公开移动端授权；浏览器内登录可截获，但不可自动化 | 见 05 文档 §3 五方案对比 |
| 课表解析 | **可行且成本已探明** | `bucm-jw-ops` skill 已有完整规则（HTML 表格 + 时间编码） |
| 通知公告 | **零门槛**，HTML 直出，约 1720 篇可翻页 | 01 文档 |
| 一卡通 | **不可做**，无公开 API，唯一入口是企业微信 e卡通 | 03 文档 §6 |
| 缴费 | **不可做**，仅微信 OAuth | 03 文档 |
| 一表通 133 流程 | **不值得做**，同一个 SPA 的实例 | 03 文档 |
| 推送/离线/组件 | **原生客户端唯一的增量价值** | 04 文档 §4 |

## 五、合规结论（最硬的门槛，务必先读 05）

| 风险等级 | 做法 | 依据 |
|---|---|---|
| 🔴 红 | 代登录、要求用户交密码、Cookie 集中托管 | 刑法 285 条 + 武昌区判例（提供 Cookie 者以从犯处理） |
| 🔴 红 | 公开上架并面向全校提供服务 | 个人无法完成「教育移动应用提供者备案」 |
| 🟠 橙 | 长期维持登录态、云同步用户数据 | 「三重授权」缺一即违法（微博诉脉脉案） |
| 🟡 黄 | 个人本机使用、数据不出设备 | 风险最低，但需隐私政策且不得转售 |
| 🟢 绿 | 只做公开数据（通知/新闻/校历） | 无授权问题 |

**唯一低成本合法路径**：北京细则（京教信〔2024〕13 号）第 18 条「校内自研自用」使用者备案 —— 代价是不能公开上架、不能对外校、不能收费。

## 六、产品建议

**三种形态，必须先选一种：**

| 形态 | 定位 | 合规 | 上架 | 建议 |
|---|---|---|---|---|
| A | 本地优先的个人学习工具（数据只在本机） | ✅ | 可尝试（需中性命名 + 非官方声明 + 隐私政策） | **MVP 首选** |
| B | 校内自研自用（走网信办备案，内测分发） | ✅ | 不上公开商店 | 做全功能版就走这条 |
| C | 面向全校的公开平台 | ❌ | 需企业主体 + 学校授权 | 不建议 |

**MVP 功能（P0，全部可落地）**：
1. 今日课表 / 下一节课倒计时（复用 KechTable 与 bucm-jw-ops 的成果）
2. 通知公告聚合（公开数据，零登录）
3. 校历 / 教学周 / 考试倒计时（本地算）
4. 统一跳转入口（教务 / BB / 一表通 / 后勤 / 图书馆）

**明确不做**：一卡通 NFC、代登录、133 个一表通流程重做、校园社交。

## 七、立即行动的 5 件事

1. **约网信办谈三件事**（数字与智慧校园建设中心，和平街 64286388 / 良乡 53911845）：
   ① 学生自研工具能否走「自研自用」备案；② CAS 能否对本校项目开放 OAuth；③ 一卡通/缴费有无对内接口。**这三个答案决定项目天花板。**
2. **把产品定位写进立项书**：明确 A/B 形态，写明「非官方」「数据不出设备」。
3. **技术选型**：Kotlin/Compose（复用 KechTable）+ SwiftUI；课表解析直接搬 skill。
4. **首版只做 P0**，用公开数据跑通闭环，再谈登录态。
5. **建立与校方的书面沟通记录**（邮件/函件），这是后续备案和免责的基础。

## 八、本轮调研的边界（诚实声明）

- ✅ 已验证：门户接口、JWT 鉴权方式、163 应用清单、30 系统移动形态、一卡通真实入口、官网数据源。
- ⚠️ 未验证：14 个 CAS 系统**登录后**的页面（需要测试账号且不越权）；一卡通接口（无公开 API）；微信小程序具体清单（平台需登录）。
- ⚠️ 环境限制：本机疑似在校园网/VPN 内（10.x 可直连），**校外访问会更差**，结论需在校外复测。
- ⚠️ 所有结论基于 2026-11-19 快照，学校系统会变。
