## 2. 图书馆卡片

白底、16dp 圆角、1dp `line`、内边距 16dp，上下两部分用 1dp 分割线分开。

### 2.1 上半：空座 + 两个按钮

| 区域 | 内容 |
|---|---|
| 左上 | "图书馆" `h2` 17sp |
| 左中 | **当前空座数 / 总空座数**：大数字 `412` 31sp SemiBold + `/2622` 16sp `text-3`；下方小字"当前空座 / 总座" 11sp `text-3` |
| 右侧（同一水平线） | 两个按钮：**座位预约**（主按钮 `brand-700` 底白字）、**空间预约**（次按钮白底蓝字蓝边）；高 36dp，圆角 10dp，间距 8dp |

- 座位预约 → 图书馆预约页（楼层折叠列表，见 [`docs/25`](25-图书馆预约页设计.md) §2）
- 空间预约 → 空间预约页（研讨室网格，见 [`docs/25`](25-图书馆预约页设计.md) §4，**原生化**）

### 2.2 下半：状态栏（三态）

| 状态 | 显示 | 样式 |
|---|---|---|
| **无预约** | 隐藏整个下半区（不占位） | — |
| **已预约（待签到）** | `● 已预约` + 座位位置 + 使用时间段 + **距签到截止 `HH:mm:ss`** | 状态点 `warning` 黄；倒计时 `danger` 红 |
| **使用中** | `● 使用中` + 座位位置 + 使用时间段 + **进度条 + 百分比** | 状态点 `success` 绿；进度条 `success` |

示例：

```
● 已预约   三期南区 A-12
  14:00–16:00      距签到截止 00:12:30
```

```
● 使用中   三层南区 A-12
  14:00–16:00         38%
  ▓▓▓▓▓▓░░░░░░░
```

规则：
- 状态点 6dp 圆点 + 状态文字 12sp。
- 座位位置 14sp `text-1`；时间段 12sp `text-2`。
- 倒计时/百分比右对齐；每秒刷新（全页共用一个 `now`）。
- "已预约"优先于"使用中"？不——按服务端状态：`待签到` → 已预约；`使用中` → 使用中；两者互斥。

## 3. 课表

### 3.1 第一行：视图切换 + 周次

```
[周视图] [日视图]              ‹ 第 12 周 ›
```

| 元素 | 规格 |
|---|---|
| 视图分段 | 两个胶囊（同 docs/18 §8.10），`brand-700` 选中；点击切换日/周 |
| 周次导航 | 右侧：`‹ 第 12 周 ›`，点击箭头切周；点"第 12 周"文字回本周 |
| 只在周视图显示周次导航 | 日视图显示 `‹ 11月24日 · 周一 ›` |

### 3.2 周视图（主视图，参考 KechTable）

| 项 | 规格 |
|---|---|
| 表头 | 两行：星期（一二三四五六日）+ 日期；**固定显示 7 天（1..7）**，不因周末无课而隐藏；日期格式 **`M/d`**（如 `11/24`）；今天一列文字 `brand-700` 加粗 |
| 节次列 | 左侧固定窄列，显示节次号 1–12（11sp `text-3`） |
| 网格 | 横向 `1dp line` 的列分割；节次行高按**绝对高度**（沿用 docs/14 的跨节排版：1–3 节按 3 个行高） |
| 课程块 | `brand-100` 底、`brand-700` 字、8dp 圆角、内边距 6dp；显示课程名（最多 2 行）+ 地点（11sp） |
| 今天高亮 | 今天那一列：表头加粗 + 背景 `brand-50` 极淡底 |
| 当前时间线 | 今天列一条 1.5dp `brand-500` 横线，随当前时间移动；不在今天则隐藏 |
| 左右滑 | 切换上一周/下一周；滑到非本周时显示"回本周"浮动按钮 |
| 冲突 | 同一时段两门课 → 并排分栏（沿用 docs/14 逻辑） |

### 3.3 日视图

| 项 | 规格 |
|---|---|
| 结构 | 单日时间轴：左侧时间刻度（08:00、10:00…），右侧课程卡片按时间先后排列 |
| 卡片 | 同周视图课程块，增加**教师**与**学分**（有则显示） |
| 空态 | "今天没有课" |
| 切换日 | 顶部 `‹ 11月24日 · 周一 ›` 支持左右滑动切日 |

### 3.4 课程详情

点任意课程块 → 底部 Sheet：课程名、教师、学分、星期/节次、周次范围、地点、"本周第几次"。
