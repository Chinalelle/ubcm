### 2.1 日期与时段

| 元素 | 规格 |
|---|---|
| 日期 | `‹ 11月24日 周一 ›`，左右箭头切天；点日期打开日历 |
| 时段 | `14:00–16:00` 可点，弹出时段选择（开始/结束，按学校可约时段） |
| 联动 | 改日期或时段后，**楼层/区域空位数重新拉取** |

### 2.2 楼层折叠列表

- 数据：`seatMenu` 返回的楼层与区域，**按接口数据渲染，不硬编码层数**
  （实测 2026-11-21 为 **二层/三层/四层/五层，共 4 层、2622 座**；一层无座位）
- 楼层行：
  - 左：楼层名（`二层`，16sp `text-1`）
  - 右：**当前空座 / 该层可预约座位数**（如 `282/282`）
  - 下：进度条（4dp，`brand-500` 填充 = 空座占比）
  - 进度条颜色：空座 ≥50% 用 `brand-500`；<15% 用 `warning`；0 用 `danger`
- **同一时间最多展开一层**：点另一层时，之前那层自动收起。
- 展开后区域行：`三层南区` + `145/145`，右侧 `›`。

### 2.3 点区域 → 区域座位页

- 复用现有 `RoomSeatMap`（docs/13 §七已实现"点区域进选座页"）。
- 页面顶部保留日期与时段，座位图按现有拖动/缩放/点座逻辑。

## 4. 空间预约页（研讨间 / 静音仓 / 朗读亭）—— 2026-11-24 实测重做

### 4.1 ⚠️ 与座位预约的结构差异（实测推翻原设计）

空间**没有楼层/区域层级**，接口直接按「类型 → 房间」返回：

| 项 | 座位预约 | 空间预约 |
|---|---|---|
| 层级 | 楼层 → 区域 → 座位 | **类型 → 房间**（无楼层/区域） |
| 数量 | 4 层 18 区 · 2622 座 | 研讨间 **24 间**（301–310、401–414）· 静音仓 **4 间** · 朗读亭 **3 间** |
| 开放时间 | 以 seatArea 规则为准 | **08:30–22:00** |
| 最短预约 | 30 分钟 | **60 分钟** |
| 最后一级 | 座位图 | **房间网格，每排 4 个** |

所以空间预约页 = **日期时段 + 类型分段 + 房间网格**，不是"楼层展开列表"。

### 4.2 接口（2026-11-24 实测，均返回 `code:0`）

| 接口 | 说明 |
|---|---|
| `GET /ic-web/roomMenu` | 空间类型：`kindId` 1 研讨间 / 2 静音仓 / 3 朗读亭 |
| `GET /ic-web/roomDevice/roomInfos` | 全部房间 + 当天已预约时段。**无参数**；`date`/`resvDates`/`resvDate` 都**不生效**（实测） |

房间对象关键字段：
```json
{
  "devId": 1, "devName": "301",
  "minResvTime": 60,
  "openTimes": [{"openStartTime":"08:30","openEndTime":"22:00","openLimit":1}],
  "resvInfos": [{"resvBeginTime":"2026-11-24 17:30:00","resvEndTime":"2026-11-24 21:30:00","resvStatus":1093}]
}
```

- `resvStatus`：`1093`=已预约；`1027`/`1029` 疑似"使用中/已签到"（**待进一步确认**）
- 实测 2026-11-24 19:30：研讨间 23/24 有预约、静音仓 4/4、朗读亭 3/3 —— 晚自习高峰几乎约满

### 4.3 页面结构

```
┌─────────────────────────────────────┐
│ ‹  空间预约                         │
│ ‹  11月24日 周一  ›    14:00–16:00  │
│ [研讨间] [静音仓] [朗读亭]           │  类型分段
├─────────────────────────────────────┤
│ ┌────┐ ┌────┐ ┌────┐ ┌────┐        │
│ │301 │ │302 │ │303 │ │304 │        │  每排 4 个
│ │空闲│ │占用│ │占用│ │空闲│        │
│ └────┘ └────┘ └────┘ └────┘        │
│ ……                                 │
└─────────────────────────────────────┘
```

| 项 | 规格 |
|---|---|
| 类型分段 | 三选一（研讨间/静音仓/朗读亭），`brand-700` 选中 |
| 网格 | **每排 4 个**，圆角方形约 72×72，gap 10dp |
| 空闲 | `brand-100` 底 + `brand-700` 房号 + "空闲"；可点 |
| 占用 | **`danger` 描边 + 淡红底** + 房号 + "占用"；不可点 |
| 占用判定 | 房间 `resvInfos` 中任一时段与**所选时段重叠** → 占用 |

### 4.4 预约提交（未实测）

- 提交接口尚未定位（写操作，属红线范围）。
- 实现前必须：先在 WebView 抓一次真实提交请求，确认路径/参数/验证码，再按**三段式**（prepare → commit 一次 → readback）实现。
- **在实测前不得声称"空间预约可用"**。
