# 28 · 登录页设计

> 版本 **v1.0** · 2026-11-24 · 上游：[`docs/17`](17-工程师交接.md) 定位、[`docs/15`](15-登录门禁.md) 门禁、[`docs/18`](18-设计系统与主题规范.md)
>
> **定位变更（重要）**：从「打开即强制门禁」改为「**缺凭证时弹登录页，但可跳过**」。
> 跳过后进首页，底部出现**红色警示栏**提示缺凭证，可关闭。

---

## 0. 一句话

登录页 = **UBCM 大字 + 账号密码 + 登录**，可"先跳过"；缺凭证时首页底部一条**可关闭的红色警示栏**。

---

## 1. 流程

```
冷启动
  ├─ 凭证齐全 → 直接进首页
  └─ 缺凭证   → 登录页（可跳过）
                  ├─ 登录成功 → 首页
                  └─ 先跳过   → 首页 + 底部红色警示栏（可关闭）
                                └─ 点警示栏 → 回登录页
```

- **不再强制**：缺凭证也能进首页，只是部分数据不可用。
- 警示栏**可关闭**（本次会话关闭，下次启动重新出现）。

---

## 2. 登录页

```
┌─────────────────────────────────────┐
│                                     │
│                                     │
│              UBCM                   │  ← 52sp，品牌蓝，字距收紧
│      北京中医药大学 · 校园助手        │  ← 13sp text-3
│                                     │
│  ┌───────────────────────────────┐  │
│  │ 学号                           │  │
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
│  │ 密码                           │  │
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
│  │          登录                  │  │  ← 主按钮
│  └───────────────────────────────┘  │
│                                     │
│            先跳过                    │  ← 文字按钮
│                                     │
│  密码只在本机与学校 CAS 通信时使用一次 │  ← 11sp text-3
└─────────────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 背景 | `bg` `#F4F7FB`，全屏，无顶栏 |
| `UBCM` | **52sp ExtraBold**，`brand-700` `#1B4A7E`，字间距 `-1px`，居中；位于屏幕垂直约 1/3 处 |
| 副标题 | "北京中医药大学 · 校园助手" 13sp `text-3`，UBCM 下方 10dp |
| 输入框 | 白底、12dp 圆角、1dp `line`、高 48dp；学号（数字键盘）、密码（密文 + 可切换明文） |
| 登录按钮 | 全宽 48dp、`brand-700` 底白字、12dp 圆角，输入非空才可点 |
| 先跳过 | 文字按钮，`text-2` 15sp，居中，距按钮 20dp |
| 说明 | "密码只在本机与学校 CAS 通信时使用一次，不保存" 11sp `text-3`，距底部 24dp |

**行为**：
- 登录中：按钮变 loading，禁止重复点。
- 失败：输入框下方红字（"学号或密码错误" / "网络异常"），不清空输入。
- 成功：进入首页，不保留密码（内存即弃）。

## 3. 首页底部警示栏

```
┌─────────────────────────────────────┐
│  … 首页内容 …                        │
├─────────────────────────────────────┤
│ ⚠ 凭证不完整，部分数据不可用  去登录 × │  ← 红色警示栏
├─────────────────────────────────────┤
│ [首页] [学习] [校园] [我的]          │
└─────────────────────────────────────┘
```

| 项 | 规格 |
|---|---|
| 位置 | **底部导航栏正上方**，固定，随页面滚动不消失 |
| 底色 | `danger` 的 10% 底（`#FDECEC`）+ 1dp `danger` 顶边 |
| 文字 | `danger` 13sp："凭证不完整，部分数据不可用" |
| 操作 | "去登录"（`danger` 加粗，点击进登录页）+ `×` 关闭 |
| 高度 | 40dp |
| 关闭 | 本次会话隐藏，不写入磁盘；下次启动重新出现 |

> 触发条件：5 条必需凭证缺任意 1 条（口径同 docs/15 §2，但不再拦截）。

---

## 4. 与 docs/15 的关系

- [`docs/15`](15-登录门禁.md) 的**凭证清单与补齐方式继续有效**；
- 但"缺凭证不许进主界面"的**强制规则作废**，改为"进得去 + 红色警示栏提示"；
- 原来"门禁是测试软件刚需"的理由（分不清红点是接口坏还是没登录）在正式产品里仍成立，
  所以警示栏要一直提示，直到凭证补齐。
