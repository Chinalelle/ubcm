# 19 · 信息架构与页面地图

> 版本 **v1.0** · 2026-11-24 · 上游：[`docs/18`](18-设计系统与主题规范.md) 设计系统
>
> 本文档定义**有哪些页、怎么走、每页放什么**。视觉规范看 `docs/18`，本文只管结构。

---

## 0. 一句话

底部 **4 个 Tab：首页 / 学习 / 校园 / 我的**。
每个 Tab 只回答学生的一个问题——**不重复、不交叉、不堆砌**。

---

## 1. 四个 Tab 的职责

| Tab | 回答的问题 | 主角 | 边界（不放什么） |
|---|---|---|---|
| **首页** | 现在该关注什么？ | 今日概览 | 不放完整列表，只放"看一眼" |
| **学习** | 上什么课、考什么、考了多少？ | 课表 | 不放生活服务 |
| **校园** | 图书馆、一卡通、通知在哪？ | 服务入口 + 实时数字 | 不放个人设置 |
| **我的** | 这个 App 本身怎么管？ | 凭证与设置 | 不放业务数据 |

> 判定一条功能放哪：**属于"学"的进学习，属于"活"的进校园，属于"我"的进我的，剩下"此刻该知道"的进首页。**

---

## 2. 导航层级

```
L1  底部 4 Tab                 ← 本地的、可来回切
L2  页内分段（≤3 项）          ← 同一 Tab 下的子分类，左右滑
L3  详情页（push + 返回）      ← 从列表/卡片点进去
L4  弹层 / 底部 Sheet          ← 轻量操作，不打断上下文
```

规则：
- **L2 分段不用于"功能入口"**，只用于同一主题的并列视图（课表/成绩/考试就是三个并列视图）。
- **从首页的任何卡片点进去，要落到对应 Tab 的对应位置**，不要开一个"孤立详情页"。
- 返回栈深度 ≤ 3；超过说明层级设计有问题。

## 3. 页面清单

### 3.1 首页 `HOME`（无分段，单页）

| 区块 | 内容 | 数据源 |
|---|---|---|
| 顶部问候 | `Hi，{用户名}` + 日期 | 本地时间 |
| **通知条** | 最新通知标题 + 未读角标，点进通知列表（L3） | 门户 |
| **常用工具与信息** | 4×2 可编辑小组件网格（1×1 / 2×1 / 2×2），默认左 2×2 余额 + 右 4 个 1×1 | 一卡通 / 图书馆 / 各系统 |
| **日程** | 最近三条（默认课表派生，支持自建） | 教务课表 + 本地 |
| **待办** | 未完成前三条（参考 DueDo：勾选/子待办/DDL 分级） | 门户待办 + 本地 |

> 首页详细规格见 [`docs/21-首页设计.md`](21-首页设计.md)，**以那份为准**。

**交互**：通知条 → 通知列表；余额组件 → 校园 · 一卡通；图书馆组件 → 校园 · 图书馆；后勤/教务组件 → 内嵌 WebView；`[课]` 日程 → 学习 · 课表；待办"查看全部" → 待办页。

### 3.2 学习 `STUDY`

**顶部固定分段：课表 · 成绩 · 考试**（默认"课表"）

| 页 | 内容 | 空状态 |
|---|---|---|
| **课表** | 周视图，默认本周；上周/下周切换；"回到今天"按钮；课程块点开详情 | "还没拿到课表，下拉刷新" |
| **成绩** | 学期切换（下拉）+ 课程成绩列表 + 学分绩点汇总 | "本学期还没有成绩" |
| **考试** | 未考（置顶，含倒计时）/ 已考，按日期分组 | "近期没有考试安排" |
| 课程详情（L3） | 课程名、教师、周次、教室、同班课程时间表 | — |

**交互**：课表左右滑切周；课程块点击 → 底部 Sheet（不跳页）。

### 3.3 校园 `CAMPUS`

**顶部固定分段：图书馆 · 一卡通 · 通知**（默认"图书馆"）

| 页 | 内容 | 空状态 |
|---|---|---|
| **图书馆** | 楼层空位概览（4 层）→ 区域座位图 → 三维筛选 → 我的预约 | "当前时段已闭馆" |
| **一卡通** | 余额大数字 + 今日消费 + 流水列表（按日分组） | "暂无消费记录" |
| **通知** | 公告列表（标题/来源/时间），点开 L3 详情；**与首页"未读通知"格共用同一列表页** | "暂时没有新通知" |

**交互**：
- 座位图是重交互页（拖动/缩放/点座），进入后全屏，顶栏收起。
- 一卡通流水支持下拉刷新。
- 通知点开是 L3 页，内含"在浏览器打开原文"。

### 3.4 我的 `ME`（无分段，单页）

| 区块 | 内容 |
|---|---|
| 顶部 | 校徽 + 姓名/学号（可脱敏显示） |
| 凭证状态 | 5 条必需凭证，每条一个状态点（有效/过期/缺失） |
| 数据体检 | 18 探针结果，默认折叠，点开才跑 |
| 设置 | 周次锚点（手动设开学周）、座位 cookie 补齐 |
| 关于 | 版本、数据来源说明、隐私说明 |
| 退出登录 | 危险色文字，二次确认 |

### 3.5 前置：登录门禁 `GATE`

- 缺凭证（5 条必需凭证缺任意一条）时**显示登录页，但可"先跳过"**，不再全屏拦截。
- 登录页：UBCM 大字 + 学号/密码 + 登录 + "先跳过"（详见 [`docs/28`](28-登录页设计.md)）。
- 跳过后进首页，底部出现**红色警示栏**（可关闭、可"去登录"）。
- 登录成功后直达首页。

## 6. 导航与状态规则

| 场景 | 行为 |
|---|---|
| 未登录 | 全屏门禁，Tab 不可见 |
| 凭证过期（`code:300`） | 对应 Tab 内显示"登录已过期，点此重新登录"，**不弹全屏** |
| 某数据源失败 | 只让该区块显示"数据获取失败 · 重试"，**不影响其他 Tab** |
| Tab 来回切 | 保留各 Tab 的滚动位置与分段选中态 |
| 从首页点卡片 | 切到对应 Tab 并定位到对应分段 |
| 座位图全屏 | 顶栏/底栏收起，返回手势退出 |
