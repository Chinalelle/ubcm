## 1. 设计原则（五条，违反即返工）

1. **白是主体**。页面底与卡片都是白/近白，任何整屏深色底一律不批（深色顶栏除外，见 §8.1）。
2. **蓝只承担"可操作 / 已选中 / 链接 / 数据"**。禁止蓝色作为大面积装饰底、禁止蓝色渐变背景。
3. **金严格 ≤ 10%**，只给三处：强调数字、徽章/进度、荣誉标识。金一多就俗。
4. **卡片用 1dp 边框，不用投影**。Material 默认浮起阴影会让界面立刻显旧——"简洁"的观感差主要来自阴影。
5. **一屏一个信息主角**。首页的主角是"下节课 + 余额"，课表的主角是"本周课"，图书馆的主角是"空位"。禁止把七件事平铺堆到首页。

## 2. 色彩

### 2.1 品牌蓝（主色系）

| Token | 色值 | 文字可用 | 用途 |
|---|---|---|---|
| `brand-900` | `#0B2545` | ✅ | 最深：大标题、深色顶栏底 |
| `brand-800` | `#123561` | ✅ | 深色顶栏渐变底（仅顶栏） |
| `brand-700` | **`#1B4A7E`** | ✅ | **品牌主色**：主按钮、Tab 选中、强调竖条 |
| `brand-600` | `#235E9C` | ✅ | 主按钮按下态 |
| `brand-500` | `#3A7BC8` | ✅ | 链接、可交互、图表主系列 |
| `brand-300` | `#8FB8EA` | ⚠️ 仅大号 | 禁用态、浅色图标 |
| `brand-100` | `#DCE9F9` | ❌ | 选中背景、标签底、课程块底 |
| `brand-50` | `#F2F7FD` | ❌ | 极浅色块（替代灰底） |

### 2.2 金（点缀）

| Token | 色值 | 文字可用 | 用途 |
|---|---|---|---|
| `gold-600` | `#A67C00` | ✅ | 金色**文字**（白底对比度 4.6:1，达标） |
| `gold-500` | `#C9A227` | ❌ | 徽章、进度环、强调数字（配深色字） |
| `gold-100` | `#F7EDCC` | ❌ | 金色浅底、奖章底 |

### 2.3 中性

| Token | 色值 | 用途 |
|---|---|---|
| `white` | `#FFFFFF` | 卡片、输入框、浮层 |
| `bg` | `#F4F7FB` | 页面底（冷白，比卡片退一档） |
| `line` | `#E2E9F2` | 分割线、卡片描边 |
| `text-1` | `#101B2B` | 正文 / 标题（藏青黑，**禁止纯黑** `#000`） |
| `text-2` | `#4E5D73` | 次要文字、副标题 |
| `text-3` | `#8C9AAD` | 占位、弱文字、未选中图标 |

### 2.4 语义色（降饱和，只在必要时出现）

| Token | 色值 | 用途 |
|---|---|---|
| `success` | `#2E9E6B` | 成功、可用、已预约 |
| `warning` | `#D99A2B` | 警告、临界、即将过期 |
| `danger` | `#D14343` | 错误、已占、危险操作 |
| `info` | `#3A7BC8` | 信息提示（同 brand-500） |

### 2.5 比例与禁用

- **配比**：白色/近白 ≈ 70%，蓝 ≈ 20%，金 < 10%。
- **禁止**：Material 默认紫、纯黑文字、蓝色渐变大色块、阴影重的浮起卡片、彩色渐变按钮。
- **红色只属于校徽**（见 §2.6）。主题色里不放红，否则红既当主题又当校徽，会互相稀释。

### 2.6 校徽使用规则（唯一的红）

- 北中医校徽是**红色圆形**标识。主题是蓝白金，红色刻意让给校徽。
- 校徽**保持原色**，不要用主题蓝或金去重绘/单色化。
- 出现位置：启动页、"我的"页顶部、登录门禁页。**全局只放这几处**，不做满屏装饰。
- 校徽是位图/矢量资源时，用圆角 999dp 裁切或原样贴出，尺寸 48–72dp。
- 它的红与 `danger` 的 `#D14343` 不是同一套语义，不要混用。

## 3. 字体与文字

字体族：**系统默认 sans-serif**（Android 即 Roboto / 中文回落到系统字体）。零自定义字体文件。

| 层级 | 字号(sp) | 字重 | 行高 | 用途 |
|---|---|---|---|---|
| `display` | 34 | SemiBold 600 | 1.2 | 余额、总分等唯一大数字 |
| `h1` | 24 | SemiBold 600 | 1.3 | 页面主标题 |
| `h2` | 20 | SemiBold 600 | 1.3 | 区块标题 |
| `title` | 17 | Medium 500 | 1.4 | 卡片标题、列表主文 |
| `body` | 16 | Regular 400 | 1.5 | 正文 |
| `caption` | 13 | Regular 400 | 1.4 | 辅助说明、时间 |
| `micro` | 11 | Regular 400 | 1.2 | 标签、角标 |

**数字规则**：
- 所有会变的数字（余额、金额、成绩、座号、倒计时）用 **tabular 数字**（`FontFeatureSetting("tnum")` 或等宽数字），避免刷新时跳动。
- 大数字前加 `¥` 时，`¥` 用小一号（如 24sp），数字保持 display。

## 4. 布局与间距

**栅格**：4dp 基准。常用档位：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40`。

| 场景 | 值 |
|---|---|
| 页面左右安全边距 | **20dp** |
| 卡片内边距 | **16dp** |
| 卡片之间垂直间距 | **12dp** |
| 区块（section）之间 | **24dp** |
| 列表行最小高度 | **60dp**（单行）/ 72dp（双行） |
| 顶部状态栏留白 | 状态栏高度 + 12dp |
| 底部 Tab 栏高度 | 64dp + 系统导航栏 |
| 内容最大宽度 | 手机竖屏全宽；横屏/平板限 600dp 居中 |

## 5. 形状与阴影

### 圆角

| 元素 | 圆角 |
|---|---|
| 卡片 | **16dp** |
| 按钮 | **12dp** |
| 输入框 / 选择器 | **12dp** |
| 标签 / 胶囊 | 999dp |
| 小方形标签 | 8dp |
| 底部弹层顶角 | 28dp |
| 头像 | 999dp |

### 阴影（克制，只有两级）

| 层级 | 用法 | 值 |
|---|---|---|
| Level 0 | **默认卡片** | 无阴影 + `1dp` `line` 描边 |
| Level 1 | 悬浮按钮、底部弹层、下拉菜单 | `0 6 20 rgba(11,37,69,0.12)` |

> 不要给普通卡片加阴影。整屏里阴影超过 2 处，就说明层级没收敛。

## 6. 图标

- **风格**：线性、`2dp` 描边、圆角端点（round cap / round join）。
- **尺寸**：Tab 24dp；列表行 20dp；按钮内 18dp；指示小图标 16dp。
- **颜色**：未选中 `text-3`、选中 `brand-700`；功能性图标可用 `brand-500`。
- **实现**：项目零第三方运行时依赖，优先用 Material Icons（`androidx.compose.material:material-icons-core`，Google 官方）或自绘 `Path`，**不要引入第三方图标库**。
- **语义**：线性 + 单一色，不允许多色插画式图标（校徽除外）。

## 7. 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| Tab 切换 / 选中态 | 150ms | ease-out |
| 展开 / 折叠 | 200ms | ease-out |
| 页面进出 | 250ms | ease-in-out |
| 加载旋转 | 循环 | linear |

**只做状态过渡**：选中、展开、加载、数值滚动。**禁止**装饰性动画、大面积位移、视差。

## 8. 组件规范

### 8.1 顶栏（TopAppBar）

- 高度 56dp，背景 = 页面底 `bg`（不要白 + 阴影），标题左对齐 `h2`/`title`，`text-1`。
- 仅当页面需要"沉浸深色"时（如座位图全屏），才用 `brand-900` 底 + 白字。
- 右侧最多 1 个操作图标。

### 8.2 底部导航（BottomBar）

- 4 个 Tab：**首页 / 课表 / 图书馆 / 我的**。
- 高度 64dp，背景 `white`，顶部 `1dp line` 分割线（无阴影）。
- 图标 24dp + 文字 `micro` 11sp，上下 4dp 间距。
- 选中：图标与文字都用 `brand-700`，字号加粗一档（500）；未选中 `text-3`、400。
- **不要**用 Material 的 `NavigationBar` 默认波浪指示器，用"图标+文字变色"即可。

### 8.3 卡片（三种）

| 类型 | 结构 | 用途 |
|---|---|---|
| **主卡 Hero** | 左侧 4dp 竖向色条（`brand-700`）+ 标题 + 内容 | 首页"下节课"、最重要的一条 |
| **信息卡 Info** | 标题（caption）+ 数值（display/title）+ 副文（caption） | 余额、消费、待办 |
| **列表卡 List** | 多行 ListRow | 待办清单、成绩、通知 |

统一：白底、16dp 圆角、16dp 内边距、1dp `line` 描边、无阴影。

### 8.4 按钮

| 类型 | 样式 | 高度 |
|---|---|---|
| 主按钮 | `brand-700` 底 + 白字、12dp 圆角 | 44dp |
| 次按钮 | 白底 + `brand-700` 字 + 1dp `brand-300` 边 | 44dp |
| 文字按钮 | 无底无框，`brand-500` 字 | 40dp |
| 危险按钮 | `danger` 底/字 | 44dp |

按钮文字 `body` 16sp、Medium 500；按下态降一档明度，不做缩放。

### 8.5 输入框

- 白底、12dp 圆角、1dp `line` 描边；聚焦时描边变 `brand-700`（1.5dp）。
- 占位文字 `text-3`，输入文字 `text-1`。
- 高度 48dp（单行）。

### 8.6 标签 / 徽章

- 胶囊：`brand-100` 底 + `brand-700` 字，11sp，内边距 8×3dp。
- 金色徽章：`gold-100` 底 + `gold-600` 字。
- 状态点：6dp 圆点，`success`/`warning`/`danger`。

### 8.7 列表行（ListRow）

- 高 60dp 起；结构 = 左图标（可选 20dp）+ 主文（title）+ 副文（caption）+ 右箭头/开关/数值。
- 行间用 `1dp line` 分割（首行不加线，末行不加线）。
- 点击态：整行 `brand-50` 底、8dp 圆角。

### 8.8 空状态（Empty State）

- 居中：40dp 线性图标（`text-3`）+ 一句主文（title）+ 一句说明（caption，`text-2`）+ 一个次要动作。
- **空状态必须说清"为什么空"和"下一步能做什么"**，禁止只放一张插画。

### 8.9 加载态

- 优先**骨架屏**（`line` 色块 + 微弱呼吸动画），不要把整页转成一个转圈。
- 局部操作（刷新余额）才用 16dp 小转圈。

### 8.10 分段控件（Segmented）

- 白底容器、`brand-100` 选中块、`brand-700` 选中字；用于"时段 / 桌子类型 / 是否全空"这类三维筛选。

## 9. 四个核心页的应用

### 9.1 首页

```
今日 11月24日 星期一 · 下午好
┌─ Hero 主卡 ─────────────────┐
│▏下节课 中医基础学            │  ← 左竖条 brand-700
│▏14:00–15:40 · 教学楼 305     │
│▏距上课 1 小时 20 分          │  ← 金色数字 gold-600
└─────────────────────────────┘
┌ 余额 ¥128.50 ┐ ┌ 今日消费 ¥23.00 ┐
┌ 未读待办 3 条 ┐ ┌ 图书馆空位 412 ┐
```

### 9.2 课表

- 网格线 `line`，表头星期 `caption` + `text-2`，今日表头 `brand-700` 加粗。
- 课程块：`brand-100` 底、`brand-700` 字，16dp 圆角；**今天**的课加 1.5dp `gold-500` 描边。
- 跨节排版保持现有绝对高度逻辑（`docs/14` 的 3 行高规则），只换视觉。

### 9.3 图书馆

- 楼层/区域空位用蓝阶表达：空得多 → `brand-500` 深、快满 → `brand-100` 浅、满 → `text-3`。
- 座位图背景 `brand-50`，桌子描边 `line`；可选座位 `brand-500`、占用 `text-3`、我预约的 `gold-500`。
- 三维筛选用分段控件（§8.10）。

### 9.4 我的

- 极简 ListRow 列表：凭证状态（每项一个状态点）、数据体检、关于、退出登录（危险色字，不加底色）。

| `Ash` | `text-3` | |

**推荐路径**：先改 `UbcmColors` 的**色值**（映射到上表），让全局立刻变蓝白金、269 处引用不动；再分批把符号名改成新语义命名（用编译错误驱动，安全）。**不要**一次性大改把逻辑一起动了。
