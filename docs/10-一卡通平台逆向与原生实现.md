# 10 · 一卡通平台逆向与原生实现

> 目标：把校园卡（余额 / 流水）做成 APP 原生能力，不再依赖 WebView 或企业微信
> 手段：**REA `analyze_web_bundle`** 定位脚本与端点 → 读源码找解密逻辑 → 客户端复现
> 结论：**成功。APP 内已完成 CAS 单点 + 解密 + 取数，余额与流水全部拿到。**

## 1. 背景：为什么一开始判断"没有接口"

一卡通不在门户的应用中心，也不在服务大厅 979 项里，而是挂在**门户首页的一个组件**：


## 3. 解密算法（核心）

`query.js` 里直接写 `response.resultData.rows` —— 说明**解密发生在请求封装层**。

去 `dkywwachat.js` 第 367 行找到了它：

```js
tempFunction(aesUtil.decrypt(response.data.substr(16), response.data.substr(0, 16)));
```

翻译成人话：

> **密文的前 16 个字符就是 AES 密钥，剩下的才是密文。**

再看 `my-encryption.js` 的 `aesUtil.decrypt`：

```js
decrypt: function (ciphertext, key) {
    let decrypt = CryptoJS.AES.decrypt(ciphertext, CryptoJS.enc.Utf8.parse(key), {
        mode: CryptoJS.mode.ECB,
        padding: CryptoJS.pad.Pkcs7
    });
    return CryptoJS.enc.Utf8.stringify(decrypt);
}
```

所以完整算法：

| 项 | 值 |
|---|---|
| 算法 | **AES / ECB / PKCS7** |
| 密钥 | **明文密文串的前 16 个字符（UTF-8 16 字节）** |
| 密文 | 剩余部分，**Base64** |
| 结果 | JSON 明文 |

**安全性评价**：密钥随密文一起下发，等于没有加密——它防的是"随手抓包的人"，不是防逆向。这也意味着客户端可以完全独立解密，不需要逆向出固定密钥。

## 4. 客户端实现

### 4.1 解密（`AesEcb.kt`）

```kotlin
fun decryptSelfContained(payload: String?): String? {
    val key = payload.substring(0, 16)
    val cipherText = payload.substring(16)
    val raw = Base64.decode(cipherText, Base64.DEFAULT)
    val c = Cipher.getInstance("AES/ECB/PKCS5Padding")   // PKCS5 == PKCS7(块长16)
    c.init(Cipher.DECRYPT_MODE, SecretKeySpec(key.toByteArray(UTF_8), "AES"))
    return String(c.doFinal(raw), Charsets.UTF_8)
}
```

### 4.2 登录链路（`EcardApi.login`）

APP 只需要一个 **CASTGC**（和门户同一个 CAS），剩下全自动：

```
GET cas.bucm.edu.cn/cas?service=<ykt SSO>(
    Cookie: CASTGC=<tgt>)
  → 302 /cas/?service=...
  → 302 /cas/login?service=...
  → 302 ykt.bucm.edu.cn/servicehall//sso/login?ticket=ST-xxx
        Set-Cookie: servicehall=<32 hex>; Path=/servicehall
  → 200 落地页（HTML 里有隐藏字段 <input id="openid" value="...">）
```

拿到 `servicehall` + `openid` 即可调接口。

> ⚠️ `openid` 不在 URL 里（只在页面隐藏字段里），`dkywwachat.js` 用 `$("#openid").val()` 取。
> 正则要兼容 `id` 与 `value` 的先后顺序。

## 6. 踩坑记录

| # | 坑 | 现象 | 解法 |
|---|---|---|---|
| 1 | 一卡通不在菜单里 | 查 163 应用 + 979 服务都找不到 | 查**首页组件库**（`sceneData` 的 `SCENE.WIDGET`） |
| 2 | 根路径 404 | `https://ykt.bucm.edu.cn/` 返回 nginx 404 | 真正的入口是 `/servicehall/sso/login`；且 DNS 指向内网 `192.168.100.63` |
| 3 | 会话 cookie 路径 | `servicehall` 的 `Path=/servicehall`，访问 `/servicehallindex`（少斜杠）会被判未登录 | 只在 `/servicehall/**` 下用；别自己拼路径 |
| 4 | 响应加密 | 接口返回 `{"data":"uV1w9b..."}` | key = 前 16 字符，见 §3 |
| 5 | openid 不在 URL | 落地页 URL 没有 `openid` | 从 HTML 隐藏字段 `#openid` 提取 |
| 6 | Ticket 一次性 | 重复用同一 ST 会失败 | 每次重新走 CAS |
