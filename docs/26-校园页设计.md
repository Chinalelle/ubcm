## 2. 校园卡卡片

白底、16dp 圆角、1dp `line`、内边距 16dp。内部三块用 1dp 分割线分开。

### 2.1 余额与今日消费

| 元素 | 规格 |
|---|---|
| 标题 | "校园卡" `h2` 17sp；右上角"打开一卡通 ›" 13sp `brand-500` |
| 余额 | `¥132.50` 31sp SemiBold（`¥` 16sp）；下方"余额" 11sp `text-3` |
| 今日消费 | 右侧：`今日消费 ¥23.00` 14sp `text-2`；金额 `text-1` |
| 打开一卡通 | 跳转 `ykt.bucm.edu.cn` 学校页面（内嵌 WebView） |

### 2.2 消费趋势（折线图）

| 元素 | 规格 |
|---|---|
| 分段 | `近 7 天` / `近 30 天`，胶囊（同 docs/18 §8.10） |
| 图 | 折线 + 面积渐变；X 轴日期（7 天显示"11/18…"；30 天显示 5 个刻度）；Y 轴自动 |
| 主色 | 折线 `brand-500`，面积 `brand-100` 40% 渐变到透明 |
| 汇总 | 图右侧或上方：区间合计（如"本周 ¥186.20"） |
| 空态 | 无流水时显示"暂无消费记录" |

### 2.3 消费区域分布（饼图）—— 用户要求"尝试设计分布"

数据来自流水 `mername`（如"良乡东院食堂一层基本伙餐厅"），**纯本地解析，无新接口**。

**解析规则**：

```
校园 = 东院 / 西院 / 其他（按 mername 里的"东院/西院"）
场所 =
  含"食堂" → 食堂 + 楼层（一层/二层，按名字里的"一层/二层"）
  含"超市" → 超市
  含"小卖部" → 小卖部
  含"开水" → 开水机
  含"咖啡" → 咖啡
  含"打印" → 打印
  其他 → 其他
标签 = 校园 + 场所（如"东院食堂一层"）
```

**饼图设计**：

| 项 | 规格 |
|---|---|
| 区间 | **跟随折线图分段**（近 7 天 / 近 30 天），中心文字同步 |
| 展示 | Top 6 分类 + "其他"，按金额降序 |
| 配色 | 蓝阶主色系：`brand-700` → `brand-500` → `brand-300` → `brand-100`，金 `gold-500` 点缀一个，其他用 `line` |
| 形状 | 环形图，直径 100dp，中间显示"本月"或"近 30 天"小字 |
| 图例 | 右侧竖排：色点 + 名称 + 百分比（`38%`） |
| 交互 | 点某块高亮该块并显示金额 |

**默认分类示例**（基于实测 mername）：

| 分类 | 示例商户 |
|---|---|
| 东院食堂一层 | 良乡东院食堂一层基本伙餐厅 |
| 东院食堂二层 | 良乡东院食堂二层风味餐厅 |
| 西院食堂一层 | 良乡西院食堂一层基本伙餐厅 |
| 西院超市 | 良乡西院超市 |
| 西院小卖部 | 良乡西院小卖部 |
| 开水机 | 良乡校区开水机 |
| 其他 | 打印、洗衣、其他 |

## 3. 小程序 / 服务入口

标题"服务"，**4 列宫格**，每项：线性图标 24dp + 文字 11sp。

| 入口 | 跳转 |
|---|---|
| 智慧后勤 | **微信 H5，App 内 WebView 打不开** → 改为唤起企业微信并提示"在企业微信 → 工作台 → 智慧后勤"；唤起失败则复制链接 |
| 智慧教务 | `jw.bucm.edu.cn`（内嵌 WebView） |
| 图书馆 | 校园 → 图书馆（同 Tab 内跳转，或直接进预约页） |
| 一卡通 | 内嵌 WebView 一卡通页面 |
| 数智北中医 | `i.bucm.edu.cn`（内嵌 WebView） |
| 更多 | 展开更多服务列表（V1 先占位） |

- 宫格卡片同样白底 16dp 圆角。
- 入口**可配置**：后续可让用户自定义排序/增删（V1 不做，先固定）。

## 4. 数据来源

| 数据 | 来源 | 现有 |
|---|---|---|
| 余额 | 流水 `balance` 字段（取最新一条） | `EcardApi.Trade.balanceYuan` |
| 今日消费 | 当天流水 `txamt` 求和 | 本地计算 |
| 近 7/30 天 | 流水按 `txdate` 聚合 | 本地计算 |
| 区域分布 | 流水 `mername` 解析 | **新增解析函数** |
| 一卡通页面 | WebView | `SchoolWebActivity` |

## 7. 待确认

1. **商户词表**：解析规则是基于少量实测样例（东院食堂一层/西院超市/开水机）推的，真实商户名可能有更多形态。首版先按关键词，遇到未覆盖的归"其他"，后续按真实流水补词表。
2. **"近 30 天"取数**：一卡通接口按页返回（226 条/12 页），30 天可能要多页；是否分页拉全量还是只取前 N 页。
