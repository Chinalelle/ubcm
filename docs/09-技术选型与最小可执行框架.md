# 09 · 安卓最小可执行框架（MVP 实测报告）

> 工程位置：`app-android/`　包名：`com.kang.ubcm`　版本：0.1.0-probe
> 构建工具：AGP 9.3.3 + Gradle 9.5.0 + Kotlin 2.2.10 + Compose（**零第三方依赖**）
> 实测环境：Android 模拟器 `duedo`（API 35，arm64）　实测时间：2026-11-19 22:00–22:10
> 实测账号：同学 / 20260000000（用户本人凭证，JWT + 教务 JSESSIONID）

---

## 1. 选型结论（已按此落地）

| 层 | 选择 | 理由 |
|---|---|---|
| Android | **Kotlin + Jetpack Compose** | 与本机已有工具链一致；先只做一端 |
| iOS | 暂缓 | 无真机、无开发者账号；WebView/小组件/推送全要原生，跨平台框架省不掉 |
| 依赖 | **零第三方** | HttpURLConnection + org.json，首次构建不用下载，最稳 |
| 网络 | 同步阻塞 + 协程 IO 调度 | 探针场景足够；正式版再换 OkHttp |
| 凭证 | SharedPreferences（正式版换 EncryptedSharedPreferences） | MVP 够用 |

> 如果将来确定要双端：只共享**数据层**（KMP），UI 各自原生。不要一开始上 Compose Multiplatform。

## 2. 工程结构

```
app-android/
├── gradle/libs.versions.toml        # 版本目录（AGP 9 / Compose BOM）
├── app/build.gradle.kts             # AGP 9：不应用 kotlin-android，只用 kotlin.plugin.compose
└── src/main/java/com/kang/ubcm/
    ├── MainActivity.kt     # Compose UI：暖白+朱砂，"体检报告"式卡片流
    ├── ProbeViewModel.kt   # 14 个探针的编排与状态机
    ├── Session.kt          # JWT 解析 + 凭证存储（刻意不接收身份证号）
    ├── Net.kt              # HttpURLConnection 封装（Bearer / 表单 / Cookie）
    ├── PortalApi.kt        # 门户 API + 防御式响应解析 + 校园卡端点探测
    └── JwApi.kt            # 教务：课表 JSON、成绩表单 POST、登录页判定
```

**UI 刻意不复用 KechTable**：暖白背景（`#FBF7F0`）+ 朱砂（`#B33A2B`）+ 墨（`#1E1B17`），
每张卡片左侧 4dp 状态色条，每组标题右侧显示 `成功数/总数`，点击卡片展开原始响应。

## 4. 三个踩坑（都已修复，写进代码注释）

### 坑 1：`adb shell` 把 cookie 的分号当命令分隔符

```bash
# ❌ 错误：设备端会把 "jsxsd=...; SERVERID_jwxt=...; JSESSIONID=..." 截断成三条命令
adb shell am start ... -e jw "jsxsd=xxx; SERVERID_jwxt=pc122; JSESSIONID=yyy"
```

现象：教务课表一直显示"未登录"，但"会话检测"却成功——因为只传了 `jsxsd` 那一段。
修复：**凭证一律走 base64**（`-e jw_b64 <base64>`），APP 端解码。

### 坑 2：登录页误判

所有教务页底部都有「湖南强智科技发展有限公司」版权，首版拿它当登录页标志 →
**正常页面全被判成"未登录"**。
修复：只认 `<title>登录</title>` / `请先登录系统` / `userLogin`。

### 坑 3（最重要）：课表不是 HTML，是 JSON

`/jsxsd/xskb/bzyXskbList` 返回 51KB，但里面 `<tr>` 只有 4 个——
**课表数据是前端 JS 拉 JSON 渲染的**，服务端 HTML 只有空壳。

真身接口（bucm-jw-ops skill 里没有记录，本次新发现）：

```
POST https://jw.bucm.edu.cn/jsxsd/xskb/loadSkzccx
  Cookie: jsxsd=...; SERVERID_jwxt=...; JSESSIONID=...
  Body:   zc=            # 空 = 全部周次
→ {"lstJx0415zb":[节次时间表], "lstKb":[34 条排课]}
```

字段含义：

| 字段 | 含义 | 例 |
|---|---|---|
| `kcmc` | 课程名 | 方药学 |
| `kch` | 课程号 | 1020205070 |
| `jg0101mc` | 教师 | 陈绍红 |
| `jx0601mc` | 教室 | 良东231教 |
| `jzwmc` | 建筑 | 教学楼(东院) |
| `kkzc` | 周次（文本） | `13-17` |
| `kkzcmx` | 周次（明细） | `,13,14,15,16,17,` |
| **`kcsj`** | **时间编码** | `30102` = 周三 1–2 节 |
| `kcsjmx` | 时间明细 | `,301,302,` |
| `ktmc` | 班级 | 岐黄班202601 |

时间编码规则：**第一位是星期几，之后每两位一个节次**（`30102` → 周三、第 01、02 节）。

## 5. 复现方式

```bash
cd "app-android"
export JAVA_HOME=/opt/homebrew/opt/openjdk@21
export ANDROID_HOME=$HOME/android-sdk
./gradlew :app:assembleDebug

adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.kang.ubcm/.MainActivity \
  -e jwt_b64 "$(cat jwt.txt | base64)" \
  -e jw_b64  "$(cat jwck.txt | base64)"
# 或启动后在 APP 内点右上角「未登录」手动粘贴
```

凭证有效期：JWT 4 小时；教务 JSESSIONID 随 CAS 会话（本次实测约 2–3 小时）。

## 6. 下一步建议

**这个框架证明了"数据层可行"，接下来该做的是产品层：**

1. **课表页**（P0）：把 34 条排课渲染成周视图网格 —— 复用 `kcsj` 编码规则与节次表，不用再逆向
2. **登录流程**（P0）：WebView 内 CAS 登录 → 截 JWT → 静默换教务会话（`cas/login?service=https://jw.bucm.edu.cn/`）
3. **凭证安全**（P0）：SharedPreferences → EncryptedSharedPreferences + Keychain 等价物
4. **首页聚合**（P1）：课表 + 公告（公开抓取）+ 待办
5. **证书/网络**：教务的 HTTP 子系统在正式版要处理 ATS（iOS）/ networkSecurityConfig（Android）

**明确不做**：校园卡余额与消费（无接口）、133 个一表通流程重做、代登录。
