# 20 · 开发提示词（P0–P7）

> **给写代码的 Agent**：按 P0 → P7 顺序执行，每份可直接复制。
>
> **视觉唯一依据**：`docs/previews/` 下的预览图（逐张对照，颜色/间距/结构以图为准）。
> **结构依据**：[`docs/19`](19-信息架构与页面地图.md)；**视觉规范**：[`docs/18`](18-设计系统与主题规范.md)。
>
> 每份做完都要：`./gradlew :app:testDebugUnitTest` 全绿 + 真机/模拟器截图 + DEVLOG 追加。

## ⚠️ 两个工程（2026-11-24 定，最重要）

| 目录 | 是什么 | 动不动 |
|---|---|---|
| `app-android/` | **测试软件**（现役测试台，验接口/算法，177 单测） | **不要动** |
| `app-prod/` | **正式软件**（新工程，包名 `com.kang.ubcm.prod`，应用名 `UBcm`） | **P0–P7 全在这里做** |

- 底层代码（网络/凭证/算法）已从 `app-android` **复制**到 `app-prod`，两边各自演进。
- 构建：`cd app-prod && ./gradlew :app:assembleDebug`
- 所有页面路径都在 `app-prod/app/src/main/java/com/kang/ubcm/`
