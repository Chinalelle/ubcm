# 27 · 空教室页设计

> 版本 **v1.0** · 2026-11-24 · 上游：[`docs/25`](25-图书馆预约页设计.md) §4 空间预约、[`docs/21`](21-首页设计.md) §4.5
>
> 界面参照「空间预约」，但**默认时间为当前**，可切换其他时段。

---

## 0. ⚠️ 先厘清：这是「查」不是「约」

学校教务只提供**空闲教室查询**（`/jsxsd/view/kbxx/kbcx/llsykb_frm.jsp`，HTML 表格、**非实时**），
**没有可调用的「预约教室」接口**。所以：

- 本页叫「空教室」，**不叫「空教室预约」**；
- 只做"查哪间空着"，不做"占教室"；
- 如果以后学校开放借用流程，再另做跳转/写操作（三段式）。

---

## 1. 结构（参照空间预约）

```
┌─────────────────────────────────────┐
│ ‹  空教室                           │
│ ‹  11月24日 周一  ›   第 5–6 节 ›   │  日期 + 时段（默认当前）
├─────────────────────────────────────┤
│ [良东] [良西] [东院] [西院]          │  教学楼分段
├─────────────────────────────────────┤
│ ┌────┐ ┌────┐ ┌────┐ ┌────┐        │
│ │101 │ │102 │ │103 │ │104 │        │  每排 4 个
│ │空闲│ │占用│ │空闲│ │空闲│        │
│ └────┘ └────┘ └────┘ └────┘        │
│ ……                                 │
└─────────────────────────────────────┘
```

与空间预约的异同：

| 项 | 空间预约 | 空教室 |
|---|---|---|
| 骨架 | 日期 + 时段 + 类型分段 + 网格 | **相同** |
| 时间默认 | 用户先选 | **当前日期 + 当前节次** |
| 分段含义 | 研讨间/静音仓/朗读亭 | **教学楼**（良东/良西/东院/西院） |
| 数据 | `roomDevice/roomInfos`（已实测） | 教务 HTML（**参数未实测**） |
| 是否可写 | 可约（待实测提交） | **只读**，不可约 |

---

## 2. 时间默认当前

| 元素 | 规格 |
|---|---|
| 日期 | 默认今天：`11月24日 周一`，可切前后天 |
| 时段 | 默认**当前节次**：按当前时间落到"第 N–M 节"（如 15:38 → 第 7–8 节），显示 `第 7–8 节 15:30–17:00` |
| 时段选择 | 点时段 → 弹层选：上午 / 下午 / 晚上，或直接选节次 |
| 当前无课间 | 若当前时间在课间/未开始，取**下一个节次** |

> 时间一改，教室网格重新拉取。

---

## 3. 教学楼分段

依据课表里的真实地点（如 `良东174教`、`良东150教`、`良东374教`）：

| 分段 | 说明 |
|---|---|
| 良东 | 良乡东院教学楼 |
| 良西 | 良乡西院教学楼 |
| 东院 / 西院 | 若接口按此拆分则显示，否则合并 |

**分段来源以 llsykb 返回的教学楼列表为准**，不硬编码。

---

## 4. 教室网格

| 项 | 规格 |
|---|---|
| 网格 | 每排 **4 个**，圆角方形约 72×72，gap 10dp |
| 空闲 | `brand-100` 底 + `brand-700` 教室号 + "空闲" |
| 占用 | **`danger` 描边 + 淡红底** + 教室号 + "占用" |
| 点击 | **不可点**（只读查询），或点击显示该教室当前课程信息（若有） |
| 空态 | "当前时段没有可用数据" + 刷新按钮 |

---

## 5. 数据源与实测缺口

| 项 | 状态 |
|---|---|
| 页面 | `/jsxsd/view/kbxx/kbcx/llsykb_frm.jsp`（需 `JSESSIONID`） |
| 形态 | HTML 表格 |
| 请求参数 | **未实测**（周次/星期/节次/教学楼怎么传，docs 没记录） |
| 实时性 | **非实时**，页面须标注「数据更新于 xx:xx」 |

> 实现前必须先实测一次：用有效教务会话 GET 该页，确认参数与表格结构。
> 在实测之前，本页只按 UI 设计推进。
