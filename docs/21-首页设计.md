## 0. 一句话

首页 = **问候 → 通知 → 可编辑小组件 → 日程 → 待办**，从上到下，长于屏幕时可滚动。

## 2. ① 问候区

| 项 | 规格 |
|---|---|
| 主文案 | `Hi，{用户名}`：`Hi，` 20sp `text-2`，用户名 **25sp SemiBold** `text-1` |
| 副文案 | `M月d日 星期X`，`caption` 13sp `text-2` |
| 右侧 | 可选 40dp 圆形头像/校徽（点击进"我的"） |
| 内边距 | 上：状态栏 + 12dp；左右 20dp；下 12dp |

## 3. ② 通知条

单行横幅，高 52dp，白底 + 1dp `line` + 12dp 圆角。

| 元素 | 规格 |
|---|---|
| 左 | 20dp 铃铛 `brand-700`；未读时右上 6dp `danger` 红点 |
| 正文 | 最新一条标题，单行省略，`body` 15sp |
| 右 | 未读数胶囊（`brand-100` 底 `brand-700` 字，11sp）+ `›` |
| 点击 | 进**通知列表页**（本轮新建）；**不得**落到校园 Tab |
| 多条 | 正文区左右滑动切换，不堆叠、不显示指示点 |
| 无通知 | 整条隐藏 |

## 4. ③ 常用工具与信息（4×2 可编辑网格）

### 4.1 网格几何

- 卡片：白底、16dp 圆角、1dp `line`、内边距 16dp、内部 gap 8dp。
- **4 列 × 2 行 = 8 个正方形单元**。
- 360dp 屏：可用宽 288dp → 单格 **66dp**；390dp 屏：单格 **73.5dp**。

| 规格 | 占用 | 尺寸（360dp） |
|---|---|---|
| `1×1` | 1 格 | 66 × 66 |
| `2×1` | 2 列 1 行（横排） | 140 × 66 |
| `2×2` | 2 列 2 行 | 140 × 140 |

### 4.2 默认布局

| 组件 | 规格 | 位置 |
|---|---|---|
| 校园卡余额 | 2×2 | col 1, row 1 |
| 图书馆 | 1×1 | col 3, row 1 |
| 空教室 | 1×1 | col 4, row 1 |
| 智慧后勤 | 1×1 | col 3, row 2 |
| 智慧教务 | 1×1 | col 4, row 2 |

### 4.3 组件规格

- **数据类（2×2）**：标签（14sp `text-2`）+ `¥` 大数字（31sp SemiBold）+ 底部副文（11sp）。
- **数据类（2×1）**：标签 + 数字横排。
- **入口类（1×1）**：图标 21dp `brand-700` + 文字 11sp `text-2`（最多 4 字，"智慧后勤"缩"后勤"）。
- **入口类（2×1）**：左图标 + 右文字（最多 6 字）。

### 4.4 点击行为

| 组件 | 去向 |
|---|---|
| 校园卡余额 | 校园 · 一卡通 |
| 图书馆 | 校园 · 图书馆 |
| 空教室 | 空教室二级页（教务 `llsykb_frm.jsp`，**非实时**，见 §4.5） |
| 智慧后勤 | 内嵌 WebView `zhhq.bucm.edu.cn/wx/#/basicHome`；白屏回退系统浏览器 |
| 智慧教务 | 内嵌 WebView 教务（复用登录态） |

### 4.5 空教室二级页（简）

| 项 | 内容 |
|---|---|
| 数据源 | 教务 `/jsxsd/view/kbxx/kbcx/llsykb_frm.jsp`（需 `JSESSIONID`） |
| 形态 | HTML 表格，**非实时** |
| 筛选 | 周次 / 星期 / 节次 / 教学楼（参数实现时实测） |
| 展示 | 空闲教室列表（楼栋 · 教室号 · 座位数） |
| 必须标注 | "数据更新于 xx:xx"；首次进入提示"非实时，仅作参考" |
| 风险 | 反爬/限流；HTML 结构可能变；解析失败显示"暂无数据"不崩 |

### 4.6 编辑交互

- 进入：卡片右上角"编辑"（`brand-500`，13sp）。
- 编辑态：组件加 2dp `brand-300` 虚线描边 → 右上角 `×` 删除 → 长按拖拽换位（落点被占则**交换**）→ 底部"+ 添加小组件"（底部 Sheet）→ "完成"退出。
- 空位显示 1dp 虚线占位框；不允许越界 4×2。
- 删空后卡片内显示"添加小组件"。

### 4.7 数据模型

```kotlin
enum class WidgetSize { S1x1, S2x1, S2x2 }
enum class WidgetType {
    BALANCE, LIBRARY_SEAT, LIBRARY, EMPTY_ROOM,
    LOGISTICS, JW, ECARD, GRADES, EXAM, NOTICE, TODO
}
data class HomeWidget(
    val id: String, val type: WidgetType, val size: WidgetSize,
    val col: Int,   // 1..4
    val row: Int    // 1..2
)
```

持久化：SharedPreferences（`home_widgets`，JSON）。首次启动写默认布局；设置页提供"恢复默认小组件"。

## 5. ④ 日程（卡片式，v1.1 改）

### 5.1 展示范围

- 首页显示**最近三条**（从当前时刻往后，含正在进行的那条）。
- 数据来源两个，**不重复存储**：
  1. 课表派生（默认，运行时计算，标记 `[课]`）
  2. 用户自建（本地持久化，标记 `[自建]`）

### 5.2 卡片结构

每条日程是**一张独立卡片**（12dp 圆角、内边距 12×14），结构：

```
┌──────────────────────────────────────┐
│ 10:00   中医基础理论          [课]    │
│  05:40  📍教学楼 305                  │
│                                       │
│ 距结束 00:17:30            82%        │
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░              │
└──────────────────────────────────────┘
```

| 区域 | 规格 |
|---|---|
| 左时间列 | 开始时间 15sp SemiBold `text-1`；结束时间 11sp `text-3` 在下 |
| 中间 | 标题 15sp `text-1`（单行省略）+ 地点行 |
| 地点 | **倒水滴 pin 图标 12dp**（`text-3` 或 `brand-500`）+ 地点 12sp `text-2` |
| 右上标签 | `[课]` / `[自建]`，10sp 胶囊 |
| 底部（仅进行中） | 倒计时 + 百分比 + 进度条 |

### 5.3 三种状态（关键）

| 状态 | 判定 | 卡片样式 | 倒计时 |
|---|---|---|---|
| **正在进行** | `start ≤ now < end` | **`gold-500` 1.5dp 边框 + `gold-100` 40% 半透明填充** | `距结束 HH:mm:ss` + **百分比** + **进度条** |
| **即将到来**（仅最近一条） | `now < start` 且是下一条 | **`brand-500` 1.5dp 边框 + `brand-100` 40% 半透明填充** | `距开始 HH:mm:ss`；**≤10 分钟时文字变 `danger` `#D14343`** |
| **普通** | 其余未来日程 | 白底 + 1dp `line` 边框 | 不显示倒计时 |

补充规则：
- 高亮**只作用于一条**：正在进行的那条用金色；若没有正在进行，则最早的那条未来日程用蓝色。其余都是普通白卡。
- 倒计时每秒刷新；`HH:mm:ss` 补零。
- 进度条：高 3dp，圆角 2dp，轨道 `line`，填充 `gold-500`；百分比取整（`Math.floor`）。
- 已经开始且已结束的课程不显示（除非"正在进行"）。
- 无结束时间的自建日程：只显示"进行中"，不显示进度条。
- 标签 `[课]` 用 `brand-100`/`brand-700`；`[自建]` 用 `gold-100`/`gold-600`。

### 5.4 交互

| 操作 | 行为 |
|---|---|
| 点 `[课]` 卡片 | 切「学习 · 课表」并定位到该课程 |
| 点 `[自建]` 卡片 | 打开编辑页 |
| 点头部"+ 添加" | 新建日程表单（§5.5） |

### 5.5 自建日程表单

字段：标题（必填）、日期（必填）、开始时间（必填）、结束时间（选填）、地点（选填）、备注（选填）、提醒（V1 不做）。

### 5.6 数据模型

```kotlin
enum class AgendaSource { TIMETABLE, USER }
data class AgendaItem(
    val id: String, val title: String,
    val startMillis: Long, val endMillis: Long?,
    val location: String?, val note: String?,
    val source: AgendaSource
)
```

- `USER` 持久化（SharedPreferences JSON）。
- `TIMETABLE` 不持久化，每次从课表实时派生。

## 6. ⑤ 待办（v1.1 新增）

> 视觉与交互参考 `mini-apps/DueDo`（只做 DDL 待办），但配色换成本项目蓝白金。

### 6.1 展示范围

- 首页显示**未完成待办的前 3 条**，排序逻辑与 DueDo 一致。
- 标题"待办" + 右侧"查看全部"（→ 待办完整页 L3）。

### 6.2 卡片结构（简略模式）

```
┌─────────────────────────────────────┐
│ ☐  写实验报告              10:28:30 │
│                            11/24    │
│                            23:50    │
└─────────────────────────────────────┘
```

| 区域 | 规格 |
|---|---|
| 左 | 方形勾选框 22dp，2dp 描边、6dp 圆角；勾选后对勾动画 + 描边转 `success` |
| 中 | 标题 15sp `text-1`（单行省略）；**有子待办时**下方显示进度条 |
| 右 | DDL 区**固定宽 64dp**：月日 13sp + 时分 11sp（`text-3`）；24h 内时月日上方加红色 `HH:mm:ss` 倒计时 |
| 卡片 | 12dp 圆角、内边距 12×14、1dp 描边 |

### 6.3 DDL 分级（照搬 DueDo 语义，换配色）

| 级别 | 判定 | 卡片底色 |
|---|---|---|
| `URGENT` | ≤24 小时（含已过期） | `gold-100` 加深一档（橙系浅底，见 §6.5） |
| `NEAR` | 3 天内 | `gold-100` 的 50% |
| `FAR` / `NONE` | >3 天 / 无 DDL | 白底 |

> 原 DueDo 用浅黄/橙；本项目沿用"暖色=临近"的语义，但整体控制在 `gold-100` 系列，不引入新色系。

### 6.4 进度条（子待办）

- 仅当有子待办时显示，高 4dp。
- **已完成部分：纯色 `brand-500`（`#3A7BC8`），不做渐变**。
- 未完成轨道：`line` 浅灰。
- 按子待办数量**等分圆形节点**（直径 8dp）：节点处轨道**断开**，圆圈内部填充**卡片底色**，不让灰线从圆圈里穿过。
  - 已完成节点：实心 `brand-500`，无描边。
  - 未完成节点：内部卡片底色 + `text-3` 描边。

### 6.5 完成动画（照搬 DueDo 四阶段）

1. 对勾路径动画（~320ms）；
2. 整卡闪烁浅绿（`success` 10% 底）**2 次**；
3. 高度收缩 + 淡出（~200ms）；
4. 下方待办上移填充，该条移入"已完成"。

### 6.6 子待办

- 点卡片主体 → **简略 ↔ 详细（展开）**切换。
- 详细模式：显示**备注（完整显示，不限行数、不截断、不加省略号）**、子待办列表（每行独立勾选框）。
- 勾掉的子待办**留在原位变灰**（`text-3` + 删除线），不移入已完成。
- 全部子待办完成 = 整条待办完成（自动走完成动画）。

### 6.7 排序（照搬 DueDo，界面层不许自己排序）

1. 距 DDL **≤24 小时**（含已过期）→ 置顶；
2. 未设 DDL 的 → 其次；
3. 其余已设 DDL → 按 DDL 由近到远。
组内按 DDL / 创建时间升序。

### 6.8 数据模型

```kotlin
enum class DueLevel { NONE, FAR, NEAR, URGENT }
data class SubTodo(val id: String, val text: String, val done: Boolean)
data class TodoItem(
    val id: String, val title: String,
    val note: String?,
    val dueAt: Long?,          // null = 无 DDL
    val done: Boolean,
    val subs: List<SubTodo>
)
```

- `dueAt` 计算：未设时分的 DDL 按当天 `23:59:59`。
- 持久化：SharedPreferences JSON。

### 6.9 编辑页（新增 / 编辑待办）

| 字段 | 控件 |
|---|---|
| 标题 | 文本输入，必填 |
| 备注 | 多行文本输入 |
| **DDL** | 文本输入框 + **右侧时钟图标**，点时钟弹出**时/分滚轮选择器**（详见 [`docs/22`](22-待办页设计.md) §5.1）；**留空 = 不设 DDL** |
| 子待办 | 逐行输入 + 删除按钮 |

### 6.10 空态

"暂无待办" + "＋ 添加待办"按钮。

## 7. 状态与空态

| 状态 | 处理 |
|---|---|
| 首页加载中 | 骨架屏：问候不动，其余区块灰块 |
| 余额失败 | 组件显示"点击重试"，不影响其它 |
| 通知失败 | 通知条显示"通知获取失败 · 重试" |
| 课表为空 | 日程只显示自建项；无则"近三天没有安排" |
| 待办为空 | §6.9 空态 |
| 全部小组件删空 | "添加小组件"占位 |

## 9. 验收清单

- [ ] 从上到下：问候 → 通知条 → 小组件卡片 → 日程 → 待办
- [ ] 小组件 4×2 网格、单格正方形、默认布局正确
- [ ] 日程为卡片式；进行中金框淡黄、即将到来蓝框浅蓝、其余白卡
- [ ] 即将到来显示距开始 `HH:mm:ss`，≤10 分钟变红
- [ ] 进行中显示距结束 `HH:mm:ss` + 百分比 + 进度条
- [ ] 地点前有倒水滴 pin
- [ ] 待办卡片：勾选框 + 标题 + DDL 固定宽 + 子待办进度条
- [ ] 进度条为**纯蓝**（无渐变），节点处轨道断开、圆圈内为卡片底色
- [ ] 展开后**备注完整显示**，不截断
- [ ] 编辑页 DDL 为**文本输入**（非选择器按钮）
- [ ] DDL ≤24h 显示红色倒计时；3 天内浅黄底
- [ ] 完成动画四阶段；子待办勾掉留原位变灰
- [ ] 单源失败不影响其它区块
- [ ] 177 单测全绿
